## Template-fit notes (for the Webflow build)

- **Use Home variant 1** (cleanest hero + logo strip + feature alternation). Variants built around code demos won't fit.
- **Hide / repurpose** AgentFlow's native sections: code playground, model/agent demo, pricing tiers, "install in seconds" — these are DevTools-specific.
- **Global colors:** map the template's accent to Tropical Green `#0099a8`; body/secondary text to Cool Gray `#7a7c81`. Keep large neutral space — the advisory position reads as confident, not loud.
- **Tone of imagery:** real operational/sector contexts over abstract AI-agent illustrations, so it doesn't read as generic or AI-generated.
